# Verification samples (Phase 6)

These two PDFs were generated by actually executing the unmodified
`lib/pdf/document-template.ts` against realistic sample data, rendered
through a real Chromium instance (Playwright, available in the build
sandbox), exactly as `lib/pdf/render-pdf.ts` does in production.

- `sample-ar-invoice.pdf` — Arabic invoice, RTL, includes the phone-number
  bidi fix found during this test
- `sample-en-quote.pdf` — English quote, LTR

They are included so the actual rendering quality can be inspected directly,
rather than taken on faith from the report text.
